# How Flutter and Google Cloud power Holafly

- **컨퍼런스**: Flutter
- **출처**: https://www.youtube.com/watch?v=GYmfO56xg6A
- **요약 일시**: 2026-09-02 09:03:39

---

## 🔑 핵심 요약
- **Holafly**는 `Flutter` 앱과 **Google Cloud** 백엔드를 함께 사용해 사용자 요청의 전체 흐름을 관찰합니다.
- 앱에서 생성한 **trace ID**를 백엔드까지 전달해 프런트엔드와 서버 요청을 하나의 트레이스로 연결합니다.
- **Google Observability**와 `OpenTelemetry`를 활용해 재현하기 어려운 버그와 실제 사용자 환경의 문제를 추적합니다.

---

## 📣 주요 발표 내용
- `Flutter` 측 통합 계층에서 사용자 동작에 대한 `trace ID`를 생성하거나 획득합니다.
- `trace ID`는 `OpenTelemetry` 기반 계측을 통해 Google Cloud 백엔드로 전달됩니다.
- 사용자가 앱에서 수행한 시점부터 백엔드가 요청을 처리하는 시점까지 end-to-end 동작을 모니터링합니다.
- 단일 사용자 요청의 프런트엔드·백엔드 상태를 함께 확인해 장애 분석 범위를 넓힙니다.

---

## 💡 개발자 포인트
- 모바일 앱과 백엔드 사이에 공통 상관관계 ID를 유지하면 분산 환경에서 요청 원인을 빠르게 좁힐 수 있습니다.
- 단위 테스트나 제한된 재현 환경만으로 찾기 어려운 문제는 실제 사용자 트레이스와 관측 데이터가 보완해 줍니다.
- `OpenTelemetry` 도입 시 앱과 서버에서 동일한 trace context를 전파하도록 네트워크 계층과 로깅 정책을 함께 설계해야 합니다.

> 사용자 식별 정보가 포함될 수 있는 트레이스·로그는 개인정보 보호 정책에 맞게 마스킹하고, 운영 환경에서는 수집 범위와 보존 기간을 명확히 관리해야 합니다.
