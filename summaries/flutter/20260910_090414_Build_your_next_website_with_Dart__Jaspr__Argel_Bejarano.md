## 🔑 핵심 요약
- **Jaspr**는 Flutter 개발자를 위해 **Dart**로 만들어진 웹 프레임워크로, SEO와 접근성이 필요한 사이트에 Flutter Web의 대안
- Jaspr는 현재 "2017년의 Flutter"와 같은 초기 단계이며, 커뮤니티의 기여와 생태계 구축이 성장의 핵심
- 코드를 "어디에 작성하느냐"가 "어떻게 작성하느냐"보다 더 중요하며, LLM은 전자를 대체할 수 없음

---

## 📣 주요 발표 내용
- **Jaspr** = Dart 기반 웹 프레임워크 (개발자: Killian)
- **Flutter Web**은 인터랙션이 많은 앱에 적합하지만, 다음 두 가지에 한계:
  - **SEO**: 검색 엔진이 콘텐츠를 크롤링하기 어려움
  - **접근성**: 스크린 리더 지원 미흡
- Jaspr는 이 두 가지 약점을 해결하는 Dart 기반 웹 개발 경로 제공
- Jaspr의 렌더링 모드 설정 방식이 유연하며, LLM이 Jaspr 코드를 매끄럽게 처리
- Flutter 커뮤니티가 Jaspr 주변 생태계 구축에 힘을 모아야 한다고 강조

---

## 💡 개발자 포인트
- Jaspr는 **서버 사이드 렌더링(SSR)** 과 싱글 페이지 앱(SPA) 모드를 지원하므로, 프로젝트 특성에 맞는 렌더링 전략 선택이 중요
- LLM 활용 시 "코드 자체를 작성하는 것"은 쉬워졌지만, **코드를 올바른 위치(생명 주기, 레이어)에 배치하는 판단**은 여전히 개발자의 몫
  > Flutter 예시: 위젯 생명 주기의 잘못된 위치에 코드를 호출하면, 수천 번 반복 실행되거나 아예 실행되지 않는 버그 발생
- "Human in the loop" — LLM이 생성한 코드를 무조건 수락하지 않고 **반드시 검토**해야 함
- Jaspr는 CSS 전역 스코프 등 기술적 한계가 있지만, "지금 기능이 없다고 미래에도 없다는 의미는 아님"
