# async* (Technique of the Week)

- **컨퍼런스**: Flutter
- **출처**: https://www.youtube.com/watch?v=YK-LeuQ7CE0
- **요약 일시**: 2026-09-02 09:05:26

---

## 🔑 핵심 요약
- Dart의 `async*`는 비동기 제너레이터를 구현해 데이터를 순차적으로 `Stream`으로 전달합니다.
- 일반 제너레이터의 메모리·실행 시간 최적화 이점을 유지하면서 `await`로 비동기 작업을 처리할 수 있습니다.
- API 업데이트처럼 시간이 지나며 발생하는 데이터를 스트림으로 내보내 호출자가 원하는 방식으로 소비할 수 있습니다.

---

## 📣 주요 발표 내용
- 동기 제너레이터는 `sync*`와 `Iterable`을 사용해 데이터를 반복적으로 반환합니다.
- 비동기 제너레이터는 `async*`와 `Stream`을 사용해 비동기 결과를 순차적으로 방출합니다.
- `async*` 함수 내부에서는 `Future`를 `await`할 수 있습니다.
- 주기적으로 API를 호출하고 상태 변경을 스트림에 추가하는 업데이트 폴링 로직에 활용할 수 있습니다.
- 호출자는 스트림을 구독해 데이터가 준비되는 대로 처리할 수 있습니다.

---

## 💡 개발자 포인트
- 한 번에 모든 결과를 메모리에 적재하지 않고 필요한 시점에 데이터를 방출하므로 대용량·지연 처리 시 유리합니다.
- API 폴링, 실시간 상태 변경, 파일·네트워크 데이터 처리처럼 비동기 데이터가 계속 생성되는 경우 `async*`를 고려하세요.
- `async*` 함수의 반환 타입은 `Iterable`이 아니라 `Stream<T>`이어야 합니다.

> `sync*`를 `async*`로 단순히 바꾸는 것만으로 끝나지 않습니다. 반환 타입을 `Stream`으로 변경하고, 호출 측에서도 스트림 구독 방식으로 소비해야 합니다.
