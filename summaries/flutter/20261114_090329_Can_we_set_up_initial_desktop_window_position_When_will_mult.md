# Can we set up initial desktop window position? When will multi-window reach stable?

- **컨퍼런스**: Flutter
- **출처**: https://www.youtube.com/watch?v=kU00pdRpfPM
- **요약 일시**: 2026-11-14 09:03:29

---

## 🔑 핵심 요약
- Flutter는 **모든 플랫폼 공통 윈도우 기능**만 제공하므로, **윈도우 초기 위치 설정**과 **메뉴 바 앱**은 직접 지원하지 않음
- 대신 **원본(raw) 플랫폼 윈도우 핸들**을 제공하므로 `FFI`로 네이티브 API를 호출해 플랫폼별 동작 구현 가능
- **멀티 윈도우 stable 출시 일정은 미정**이며, 현재 Material·Cupertino의 새 윈도우 기능 대응에 집중 중

---

## 📣 주요 발표 내용
- 윈도우 초기 위치 설정·메뉴 바 앱은 일부 플랫폼만 지원하는 기능이라 Flutter 프레임워크 차원의 API는 제공하지 않음
- Flutter는 **네이티브 플랫폼 윈도우 핸들**을 노출함
- 데스크톱 플랫폼에서 새 윈도우 기능을 쓰도록 **Material / Cupertino** 위젯 라이브러리 업데이트 진행 중
- 커뮤니티 피드백을 바탕으로 윈도우 기능을 계속 개선할 예정

---

## 💡 개발자 포인트
- 초기 윈도우 위치·메뉴 바 앱 같은 플랫폼 전용 기능은 **윈도우 핸들 + `dart:ffi`** 로 네이티브 API(Win32, AppKit, GTK 등)를 직접 호출해 구현해야 함
- 플랫폼별 분기 코드가 필요하므로 데스크톱 타깃별 네이티브 구현 및 테스트 부담을 감안할 것
> ⚠️ 멀티 윈도우 기능은 아직 stable 일정이 없으므로, 프로덕션 앱에 도입할 때는 API 변경 가능성에 유의
- 윈도우 기능 관련 요구사항은 Flutter 팀에 피드백으로 전달하면 개선에 반영될 수 있음
