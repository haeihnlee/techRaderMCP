# A2UI 0.9.0 and GenUI

- **컨퍼런스**: Flutter
- **출처**: https://www.youtube.com/watch?v=Ig-zOsnU5F4
- **요약 일시**: 2026-08-14 09:03:51

---

## 🔑 핵심 요약
- **A2UI 0.9** 프로토콜 채택으로 `GenUI` 패키지 아키텍처가 전면 개편됨
- `ContentGenerator` 제거 후 Engine / Transport / Conversation 3계층으로 분리되어 에이전트 연결 방식이 자유로워짐
- "구조화 출력 우선"에서 **"프롬프트 우선"** 방식으로 전환, 새로운 `PromptBuilder` 클래스 도입

---

## 📣 주요 발표 내용
- **`ContentGenerator` 클래스 제거**: 기존 LLM 네트워크 호출·응답 파싱을 감싸던 클래스가 없어짐
- **새 3계층 구조** 도입:
  - `Engine`: UI 상태 및 렌더링 관리
  - `Transport` (TransportAdapter): 에이전트 ↔ 클라이언트 메시지 스트리밍
  - `Conversation`: 인터랙션 관리용 편의 파사드 클래스
- **`PromptBuilder`** 신규 도입: 카탈로그와 추가 지시사항을 받아 A2UI 스키마 포함 시스템 프롬프트 자동 생성
- **`GenUI` prefix 제거**: 대부분의 핵심 클래스에서 `Genuine` 접두어가 삭제됨
- `CoreCatalogItems` → `BasicCatalogItems` 로 이름 변경
- `GenuineFunctionDeclaration` / tools → **`ClientFunction`** 으로 통일
- 자체 메시징 타입 제거, 별도 **`JNI Primitives`** 패키지(`ChatMessage`, `MessagePart` 등) 분리
- 신규 기능: 클라이언트 **커스텀 함수**, 모듈러 스키마, 개선된 에러 핸들링

---

## 💡 개발자 포인트
> **Breaking Change**: A2UI 0.9 프로토콜 변경으로 JSON 페이로드 구조가 바뀌었습니다. 직접 A2UI JSON을 구성하거나 특정 페이로드 구조에 의존하는 코드는 반드시 마이그레이션이 필요합니다.

- `ContentGenerator`를 사용하던 모든 코드는 `TransportAdapter`의 `onSend` 콜백 방식으로 재작성 필요
- 프로바이더 전용 래퍼 패키지(기존 content generator 기반)는 더 이상 필요하지 않음
- LLM 모델·프로바이더 선택이 자유로워지고, 생성 설정·커스텀 함수 추가가 프레임워크 API 없이 가능
- `PromptBuilder.systemPrompt` 문자열을 직접 LLM에 전달하는 방식이므로 **프롬프트 컨텍스트 관리**를 앱이 직접 담당
- 테스트 시 토큰을 직접 주입할 수 있어 **목(mock) 에이전트 테스트**가 단순화됨
