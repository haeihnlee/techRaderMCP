# Client side functions for Flutter GenUI

- **출처**: https://www.youtube.com/watch?v=86R2NXSCDrg

## 🔑 핵심 요약
- 생성형 UI 앱에서 가격 계산·통계·통화 서식 같은 작업을 LLM에 맡기면 **지연 시간**이 늘고 **환각(hallucination)**도 생김
- **A2UI 클라이언트 측 함수(client-side functions)**를 쓰면 LLM이 이런 계산을 기기에서 로컬로 실행되는 Dart 코드에 넘김
- 결과는 **결정론적이고 정확**하며, 서버를 왕복하지 않아 더 빠름

## 📣 주요 발표 내용
- 발표자: Flutter 팀 Andrew. 오픈소스 셰프 어시스턴트 앱(자막상 "Come Me")으로 시연
- 시연 상황: "어시스턴트가 재료 가격을 지어낸다"는 버그를 클라이언트 함수로 해결
- 패키지의 **동기식 클라이언트 함수** 기반 클래스를 상속해 `CalculateCostFunction` 서브클래스를 만듦
- 함수 정의 구성 요소:
  - 고유 이름 문자열: `calculateCost` (LLM이 A2UI 페이로드에서 이 이름으로 함수를 참조)
  - 무엇을 계산하고 어떤 형식으로 반환하는지 적은 **설명(description)**
  - 반환 타입: `string`
  - **JSON 스키마 빌더**로 정의한 인수 스키마 (재료 ID 문자열 + 수량 숫자)
  - `executeSync` 구현: 인수를 파싱하고 로컬 비용 서비스를 호출한 뒤 달러 서식 문자열을 반환
- 클라이언트 함수는 UI 컴포넌트는 아니지만 **카탈로그 항목의 일종**임 (에이전트에게 함수를 언제, 어떻게 쓰는지 알려줌)
- 카탈로그를 만들 때 **functions 매개변수**에 다른 카탈로그 항목과 함께 함수를 등록
- GenUI 프롬프트 빌더는 카탈로그를 자동으로 검사해 함수 선언(스키마·설명)을 **시스템 프롬프트**로 바꿔 줌
- 에이전트는 가격을 직접 계산하지 않고 `calculateCost` 호출 표현식을 A2UI 메시지에 넣어 보냄
- **GenUI 표면 컨트롤러(surface controller)**가 이 표현식을 로컬에서 평가해 정확한 값을 화면에 그림

## 💡 개발자 포인트
- 금액·수치·서식처럼 **틀리면 안 되는 로직**은 LLM 대신 클라이언트 함수로 옮기면 정확성을 보장할 수 있음
- 함수의 **이름·설명·인수 스키마**가 에이전트가 함수를 언제 호출할지 판단하는 기준임. 설명은 분명하게 작성할 것
- 카탈로그에 등록만 하면 시스템 프롬프트에 자동 반영되므로 프롬프트를 손으로 고칠 필요가 없음
- 동기식 함수라서 서버 왕복이나 무작위성 없이 바로 결과가 나와 **UI 반응성**이 좋아짐
- 일반 Dart/Flutter 코드이므로 **stateful hot reload**로 바로 수정하고 확인할 수 있음
- 참고 자료: **GenUI 입문 코드랩** (약 1시간 남짓에 앱 하나를 처음부터 완성), 예제 코드는 GitHub `flutter/demos` 저장소

> 주의: 자막에는 프로토콜 이름이 "ATUI"로 나오지만 Google의 **A2UI**를 가리키는 것으로 보입니다. 클래스명 `CalculateCostFunction`과 메서드명 `executeSync`도 음성 자막에서 추정한 이름이니, 정확한 API명은 `genui` 패키지 문서와 `flutter/demos` 코드에서 확인하세요.
