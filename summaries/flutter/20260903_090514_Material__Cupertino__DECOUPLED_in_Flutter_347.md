# Material & Cupertino == DECOUPLED in Flutter 3.47!

- **컨퍼런스**: Flutter
- **출처**: https://www.youtube.com/watch?v=U1hcyr_QeOc
- **요약 일시**: 2026-09-03 09:05:14

---

## 🔑 핵심 요약
- **Flutter 3.47**부터 `Material` 및 `Cupertino` UI 라이브러리를 핵심 SDK와 분리된 독립 패키지로 선택해 사용할 수 있습니다.
- 독립 패키지는 `pub.dev`에서 **버전 1.0**에 도달했으며, SDK 전체 업그레이드 없이 UI 버그 수정과 기능 개선을 배포할 수 있습니다.
- 기존 의존성은 새로운 **Material UI 호환성 브리지**를 통해 점진적으로 마이그레이션할 수 있습니다.

---

## 📣 주요 발표 내용
- `Material` UI와 `Cupertino` UI가 각각 독립적인 릴리스 로드맵으로 발전할 수 있도록 디커플링되었습니다.
- 현재 핵심 SDK에도 디자인 위젯이 포함되어 있지만, 해당 위젯들은 **2026년 11월** 정식 지원 중단(deprecation)이 예정되어 있습니다.
- 독립 UI 패키지로 전환하면 핵심 Flutter SDK 릴리스 주기와 별개로 UI 패키지의 버그 수정과 신규 기능을 받을 수 있습니다.
- 마이그레이션 과정에서 기존 서드파티 패키지의 import 호환성을 유지하도록 브리지 계층이 제공됩니다.
- Flutter 3.47로 업그레이드한 뒤 제공되는 마이그레이션 절차를 이용해 기존 import를 자동으로 정리할 수 있습니다.

---

## 💡 개발자 포인트
- **UI 패키지와 SDK의 릴리스 주기 분리**로 특정 버튼이나 위젯의 수정만 빠르게 적용할 수 있어, 전체 SDK 업그레이드 부담이 줄어듭니다.
- 앱과 플러그인의 `Material`·`Cupertino` import 및 의존성 범위를 점검하고, 독립 패키지 전환 계획을 세우는 것이 좋습니다.
- 호환성 브리지가 기존 서드파티 의존성을 지원하더라도, 전환 전후에 빌드·테스트와 테마·위젯 동작을 확인해야 합니다.

> **주의:** 핵심 SDK에 포함된 디자인 위젯은 2026년 11월 정식 지원 중단이 예정되어 있으므로, 장기 유지보수 프로젝트는 독립 패키지로의 마이그레이션을 미루지 않는 편이 안전합니다.
