# if-case statements (Technique of the Week)

- **출처**: https://www.youtube.com/watch?v=m-vM9FS6DAk
- **요약 일시**: 2026-10-21 09:03:31

---

## 🔑 핵심 요약
- Dart의 **`if case` 문**은 값 하나를 패턴과 맞춰 보고, `if` 조건 안에서 바로 **구조 분해**까지 해 줍니다
- JSON 검증처럼 타입 확인, 키 확인, 캐스팅을 반복하던 **상용구 코드**를 패턴 하나로 줄일 수 있습니다
- case가 하나뿐인 `switch` 문 대신 쓰면 코드를 읽기가 더 쉬워집니다

---

## 📣 주요 발표 내용
- **패턴 매칭**은 데이터의 형태를 분석하고 비교하는 언어 기능이며, 주로 `switch` 문에서 쓰입니다
- 예시: JSON에 `name`, `age` 키가 있는지 검증하는 상황
- 일반 `if` 문으로 쓰면 타입 확인, 키 존재 확인, 요소별 캐스팅을 모두 손으로 해야 합니다
- case가 하나뿐인 `switch` 문은 나중에 코드를 읽는 개발자를 헷갈리게 할 수 있습니다
- `if case` 를 쓰면 이 검증 로직이 읽기 쉬운 패턴 하나로 줄어듭니다
- 패턴이 맞으면 `name`, `age` 변수가 **본문 스코프 안에 바로 바인딩**됩니다
- 패턴이 맞지 않으면 `else` 블록이나 그다음 코드로 넘어갑니다

---

## 💡 개발자 포인트
- `if case` 에는 **레코드**, **컬렉션(List/Map)**, **사용자 정의 객체** 패턴을 모두 쓸 수 있습니다
- `when` 키워드로 **가드 절**을 붙이면 조건을 더 세밀하게 걸 수 있습니다
- 예: `if (json case {'name': String name, 'age': int age}) { ... }`
- 분기가 하나뿐인 패턴 검사는 `switch` 보다 `if case` 가 의도를 더 잘 드러냅니다
- JSON 파싱이나 API 응답 검증 코드에 적용하면 타입 안전성과 가독성을 함께 챙길 수 있습니다
- 자세한 내용은 `dart.dev` 의 패턴 문서를 참고하세요

> 패턴 매칭은 Dart 3.0 이상에서 쓸 수 있습니다 (`pubspec.yaml` 의 SDK 제약 조건을 확인하세요)
