# How do I automatically update Skills for Dart and Flutter?

- **컨퍼런스**: Flutter
- **출처**: https://www.youtube.com/watch?v=37i6b3TT2kM
- **요약 일시**: 2026-11-21 09:03:30

---

## 🔑 핵심 요약
- Dart/Flutter **Skills**를 자동으로 업데이트하려면 에이전트 공식 마켓플레이스에서 **에이전트 플러그인**으로 설치하면 됨
- 현재 공식 등록 마켓플레이스는 **Anti-Gravity**와 **Cursor**이고, 다른 인기 에이전트 마켓플레이스도 등록 작업 중
- Skills만 따로 수동 설치할 수도 있지만, 이 경우 프로젝트마다 직접 업데이트해야 함. Flutter 팀은 플러그인 방식을 **강력 권장**

---

## 📣 주요 발표 내용
- 인기 에이전트 대부분이 마켓플레이스로 설치한 플러그인의 자동 업데이트를 지원함
- Dart/Flutter 에이전트 플러그인이 **Anti-Gravity**, **Cursor** 마켓플레이스에 공식 등록됨
- 에이전트 플러그인에는 **Skills**, **MCP 서버**, **규칙(rules)** 등 여러 AI 도구가 함께 들어 있음
- 플러그인은 마켓플레이스로 설치하든 수동으로 설치하든 같은 구성 요소를 모두 쓸 수 있음
- 필요한 Skill이나 부족한 점은 Flutter 팀에 피드백으로 요청할 수 있음

---

## 💡 개발자 포인트
- Cursor나 Anti-Gravity를 쓴다면 마켓플레이스에서 플러그인을 설치해 Skills를 자동으로 최신 상태로 유지할 수 있음
- Skills만 수동으로 설치했다면 프로젝트(워크스페이스)마다 아래 명령으로 직접 업데이트해야 함
  - `npm skills update`
  - `dart run skills ...` (영상 자막에는 "`dart run skills at get`"으로 표기됨. 정확한 하위 명령은 공식 문서에서 확인 필요)

> ⚠️ 수동 설치는 자동 업데이트가 되지 않음. 여러 프로젝트를 관리한다면 각 워크스페이스에서 따로 업데이트해야 하므로 버전이 프로젝트마다 달라지기 쉬움
