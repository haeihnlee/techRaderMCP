## 🔑 핵심 요약
- **Flutter + LiteRT-LM + Gemma 4** 조합으로 네트워크 없이 기기 안에서 도는 **온디바이스 AI**를 만들 수 있음
- 클라우드 LLM만 쓸 때 생기는 세 가지 문제(**개인정보 보호**, **네트워크 연결**, **토큰당 비용**)를 로컬 추론으로 해결
- "앱 하나, 추론 엔진 하나, 모델 하나"로 한 번 빌드하고 한 번 프롬프트를 작성해 Android·iOS·웹·데스크톱 등 여러 플랫폼에 배포

## 📣 주요 발표 내용
- **LiteRT-LM**: Google이 만든 상용 수준의 LLM 추론 엔진. Android, iOS, 웹, 데스크톱, IoT를 지원
- 지원하는 하드웨어에서는 **GPU / NPU 가속**을 쓸 수 있음
- Flutter용 **공식 패키지**를 pub.dev에서 받을 수 있음 (Google AI Edge 팀이 지원)
- Flutter 패키지가 깔끔한 API를 제공하고 **채팅 대화 기록**을 대신 관리해 줌
- **Gemma 4**: Gemini와 같은 연구·기술로 만든 경량 오픈 모델 제품군, **Apache 2.0** 라이선스로 상업적 사용 가능
- 모델 바이너리: Hugging Face에서 최적화된 **Gemma 4 LiteRT-LM 바이너리**를 받음
- 데모 1: 사진 폴더를 사용자가 정한 기준으로 자동 분류하는 앱. 도구 호출로 폴더를 만들고 파일을 옮기며, 모두 오프라인으로 동작
- 데모 2: Flutter Scene으로 만든 **Dash Infinite Runner** 게임. Gemma 4 12B로 실시간 해설을 생성하고 Windows에서는 NPU 가속을 사용
- 프로토타입 미리보기: Gemma가 커스텀 **GenUI** 컴포넌트로 응답하는 화면 (자세한 내용은 다음 영상에서 다룰 예정)

## 💡 개발자 포인트
- 기본 흐름: **엔진 생성 → 모델 로드 → 채팅 생성 → 메시지 추가 → 응답 토큰 비동기 스트리밍 수신**
- **채팅(세션)** 기능
  - 대화 기록 저장
  - 컨텍스트가 가득 차면 자동 정리
  - 도구 호출 처리
- 채팅 세션을 용도별로 여러 개 만들 수 있음 (예: 텍스트 요약용, 사용자 응답 분석용)
- **모델 가중치는 한 번만 로드**되어 모든 세션이 공유하고, 컨텍스트는 세션마다 따로 유지됨
- 입력은 **멀티모달**: 텍스트·이미지·오디오를 지원
- 문서는 페이지 스크린샷으로, 영상은 스틸컷(프레임) 묶음으로 넣는 방식으로 활용 가능
- **도구 호출(Tool calling)**: Gemma가 응답에 도구 호출을 담아 보내면, 앱이 그 작업을 실행하고 결과를 다시 Gemma에 넘겨줌

> ⚠️ 모델 파일이 **약 3GB**입니다. 앱을 처음 실행할 때 한 번만 받아 **로컬에 저장**하고, 다운로드 전에 **Wi-Fi 연결 여부를 확인**하세요. 그렇지 않으면 사용자의 모바일 데이터를 크게 소모할 수 있습니다.

> ⚠️ 데모는 Hugging Face에서 직접 받았지만, 실제 서비스에서는 **Firebase** 같은 클라우드 스토리지로 배포하는 것을 권장합니다.

- 다음 단계로 고려할 것
  - **파인튜닝**: 앱 도메인 데이터로 Gemma 4를 특화
  - **에이전트 스킬**: 도구 호출에서 한 단계 더 나아가, 목표를 이루기 위한 구체적인 작업 지침을 제공
  - **하이브리드 아키텍처**: 기본은 로컬 추론으로 처리하고, 복잡한 추론이 필요할 때만 클라우드 모델로 보냄

## 📅 버전 / 출시 일정
| 모델 | 규모 | 권장 환경 |
|---|---|---|
| Gemma 4 `E2B` | 소형 | 모바일(iPhone, Pixel), 브라우저(Chrome), 엣지 |
| Gemma 4 `E4B` | 소형 | 모바일(iPhone, Pixel), 브라우저(Chrome), 엣지 |
| Gemma 4 `12B` | 대형 | 고성능 노트북·데스크톱 (Dash 게임 데모에서 사용) |
| Gemma 4 `26B` (활성 파라미터 4B) | 대형 | 고성능 노트북·데스크톱, 단일 GPU 클라우드 |
| Gemma 4 `31B` | 대형 | 고성능 노트북·데스크톱, 단일 GPU 클라우드 |

- 출시 일정은 발표되지 않음
- 모델 크기를 고를 때는 **크기 ↔ 속도 ↔ 기능** 사이의 절충을 따져야 함
