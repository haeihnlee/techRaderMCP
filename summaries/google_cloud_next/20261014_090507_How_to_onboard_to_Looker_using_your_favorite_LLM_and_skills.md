# How to onboard to Looker using your favorite LLM and skills

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=U58Pb0Xdi3w
- **요약 일시**: 2026-10-14 09:05:07

---

## 🔑 핵심 요약
- Looker가 **오픈소스 Looker 스킬(skills) 저장소**를 GitHub에 제공하며, AI 에이전트가 이를 읽고 첫 LookML 프로젝트 구축을 단계별로 안내
- **스킬**은 특정 작업(신규 프로젝트 구축, 기존 프로젝트 감사 등)을 잘 수행하는 방법을 자연어로 적은 마크다운 파일(`skill.md`)로, LLM과 사람 모두 읽을 수 있는 가이드
- 에이전트는 연결 → 프로젝트 → 뷰 → 모델 → 배포의 **5단계 로드맵**을 제시하고, 탐색기(Explore)에서 첫 쿼리를 실행하는 것까지 대화형으로 안내

---

## 📣 주요 발표 내용
- **Looker 스킬 저장소** 공개 (오픈소스, GitHub)
- 온보딩 스킬: 처음 Looker에 로그인한 사용자를 위한 온보딩 가이드 역할
- 사용 방법 1 — **에이전트형 IDE**(Antigravity, Claude Code 등. 자막에는 "Cloud Code"로 표기): 에이전트를 Looker 스킬 저장소에 연결한 뒤 프롬프트로 요청
- 사용 방법 2 — **웹 채팅 인터페이스**(Gemini, Claude 등): 저장소를 내려받아 스킬 폴더를 채팅창에 업로드하거나, 해당 도구의 검색 기능으로 저장소 링크를 찾아 읽게 함
- 에이전트가 중앙의 `skill.md`를 분석해 일반 튜토리얼 대신 사용자 상황에 맞춘 로드맵 제공
- 각 단계마다 Looker 핵심 개념 설명 (예: 뷰가 DB 테이블에 매핑되는 방식, 모델이 프로젝트 정의에 핵심인 이유)
- 단계마다 **체크포인트**를 두어 학습 내용을 확인

> 현재는 에이전트가 Looker에 **직접 연결할 수 없음** — 에이전트가 알려주는 단계를 사용자가 Looker UI에서 직접 수행해야 함 (연결용 도구는 있으며, 온보딩 과정에서 소개됨)

## 💡 개발자 포인트
- 권장 프롬프트 예시: *"Looker 스킬 GitHub 저장소에서 온보딩 스킬을 읽고, 첫 번째 LookML 모델 설정을 안내해 줘. 한 번에 한 단계씩 진행해서 배우면서 할 수 있게 해 줘."*
- IDE 에이전트는 코드를 전부 대신 작성하려 할 수 있으므로 **"내가 Looker에서 직접 따라 할게, 무엇을 할지만 알려줘"**처럼 명확히 지시하는 것이 좋음
- 에이전트가 먼저 **DB 연결이 이미 있는지** 묻고, 있으면 바로 2단계(프로젝트 생성)로 건너뜀 → Looker UI 클릭 경로와 이유를 함께 안내
- 탐색기가 예상과 달리 자동 생성되지 않아도 *"아직 탐색기가 없어요. 간단한 걸로 하나 제안해 줘"*처럼 요청하면 함께 만들어 나갈 수 있음
- 첫 쿼리: 탐색기에서 새로 모델링한 **차원(dimension)** 선택 → **측정값(measure)** 추가 → 실행
- 익숙해지면 스킬을 팀 워크플로우에 통합하고, 저장소에 **자체 비즈니스 로직·아키텍처 규칙 스킬**을 추가해 확장 가능
- 오픈소스이므로 문제나 빠진 온보딩 내용이 있으면 변경 제안(PR)이나 이슈 등록 가능, 저장소에 star를 눌러두면 업데이트 알림을 받을 수 있음
