# I built an AI Agent to run my channel

## 🔑 핵심 요약
- 대부분의 AI 에이전트는 **단일 프롬프트**로는 실행 순서·안전성 검사·사람 승인을 보장할 수 없어 프로덕션에서 실패한다는 문제의식에서 출발
- Google **Agent Development Kit(ADK)**로 완전 자율형 **멀티모달 AI 비디오 스튜디오**를 처음부터 구축하는 데모
- 예시 시나리오: 매일 "cozy-spooky" 영상을 올리는 가상 채널 **"VibeTube"** 운영 자동화

---

## 📣 주요 발표 내용
- 시청자 입력이 **음성 메모, 현관 영상, 으스스한 사진, 텍스트 댓글** 등 멀티모달 형태로 매일 밤 들어오는 상황을 가정
- **Gemini**가 멀티모달 입력을 읽고 이해
- **Imagen**이 포스터(썸네일) 이미지 생성
- **Veo**가 최종 영상 렌더링
- ADK로 이들 모델을 하나의 에이전트 파이프라인으로 엮음

---

## 💡 개발자 포인트
- 프로덕션 에이전트는 프롬프트 하나에 모든 것을 맡기지 말고 **단계 순서 보장**, **안전성 검사**, **human-in-the-loop 승인**을 구조적으로 설계해야 함
- ADK를 이용해 Gemini·Imagen·Veo 같은 생성형 모델을 **워크플로 단위로 오케스트레이션**하는 패턴 참고용
- 멀티모달 사용자 입력(음성·영상·이미지·텍스트)을 한 파이프라인에서 다루는 예제로 활용 가능

> 영상 설명이 중간에 잘려 있어 구체적인 ADK API·에이전트 구성 방식은 이 요약에 포함되지 않았습니다.
