# How Antigravity Evaluates a LangGraph Agent

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=-7GgFPFY4WI
- **요약 일시**: 2026-10-06 09:08:53

---

## 🔑 핵심 요약
- **Antigravity**(Google의 에이전트형 IDE)가 **LangGraph** 기반 에이전트의 평가(Evaluation) 작업을 스스로 계획하고 진행하는 과정을 보여주는 짧은 데모
- 작업 전에 **아키텍처 개요**와 **구현 계획(Implementation Plan)**을 먼저 제시해 실제 구현 방식을 확인할 수 있음
- LangGraph 트레이스를 **OpenInference** 형식으로 변환해 에이전트 평가 데이터로 활용

> ⚠️ 원본 자막이 매우 짧아(1분 미만 분량) 데모의 일부 장면만 요약에 반영되었습니다.

---

## 📣 주요 발표 내용
- **아키텍처 개요 자동 제시**: Antigravity가 매 작업마다 아키텍처 개요를 보여줘 구현 방향을 사전에 검토 가능
- **구현 계획 수립**: "LangGraph 에이전트 평가 + **OpenInference Trace 변환**"을 골자로 한 계획을 에이전트가 직접 작성
- **로컬 환경 인식**: 이미 로컬에 설치된 도구들과 **Docs Hound**의 로컬 버전을 스스로 파악하고 활용
- **트레이스 기반 평가 데이터 확보**: 다른 에이전트가 실행하며 남긴 트레이스를 수집해 평가용 데이터셋으로 사용

---

## 💡 개발자 포인트
- LangGraph 에이전트를 평가하려면 실행 **트레이스 수집 → 표준 포맷(OpenInference) 변환 → 평가** 파이프라인을 구성하는 것이 핵심
- **OpenInference**는 OpenTelemetry 기반 LLM/에이전트 트레이싱 규격이므로, 평가 도구(Phoenix 등)와 연동 시 이 포맷으로 맞춰두면 재사용성이 높음
- Antigravity 같은 에이전트형 IDE를 쓸 때는 **구현 계획 단계에서 아키텍처를 검토**한 뒤 실행을 승인하는 흐름이 효과적
- 로컬에 이미 존재하는 도구/에이전트를 에이전트가 탐지해 재사용하므로, 개발 환경의 도구 구성을 정리해두면 자동화 품질이 올라감

> 자막 정보가 제한적이어서 구체적인 API·설정·평가 지표는 원본 영상에서 직접 확인이 필요합니다.
