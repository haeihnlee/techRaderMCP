# Tell your data story with Looker Data Apps

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=WWG-wIaB4aQ
- **요약 일시**: 2026-10-31 09:03:39

---

## 🔑 핵심 요약
- Google Cloud Tech 채널 진행자의 마지막 방송으로, 진행자의 구글 입사 과정을 **Looker Data Apps** 여러 개로 보여주는 데모 영상
- Data App 하나에 **인터랙션(GIF·애니메이션·호버)**과 **데이터 지표**를 함께 담아 "데이터로 이야기하기(data storytelling)"를 구현
- 일부 인터랙션은 **에이전트 + Looker** 조합으로 구현했다고 언급

---

## 📣 주요 발표 내용
- **영화관 Data App**: 공공 데이터셋 **IMDb**에서 가져온 실제 지표로 진행자가 근무하던 2년간 인기 영화 Top 10을 GIF와 시각화로 표시
- **호수 수질 연구 Data App**: 호수 shape 파일에 마우스를 올리면 헬리콥터 애니메이션이 움직이고 해당 호수의 데이터가 표시됨 → 스크롤하면 핵심 지표 확인 가능
- 호버 인터랙션은 **에이전트와 Looker**로 구현 (구체적인 API·설정은 영상에서 다루지 않음)
- **연구 이력 Data App**: 애디론댁(Adirondack) 호수 연구부터 병원 NLP(자연어 처리·감성 분석) 데이터까지 정리
- **약국 데이터 분석가 시절**: 경영진 보고 경험을 통해 **검증된 데이터**, **거버넌스가 적용된 데이터**, **중앙 집중화된 지표**의 중요성을 강조
- **Twitch 라이브 코딩 Data App**: 매주 목요일 스트리밍 영상 목록과 Twitch 분석 데이터를 함께 표시

---

## 💡 개발자 포인트
- Looker Data App은 대시보드 위에 **커스텀 시각화·애니메이션·호버 인터랙션**을 얹어 지표와 인터랙션을 한 화면에서 제공할 수 있음
- 지도/shape 파일 기반 인터랙션 + 하단 지표 섹션 구성은 지리 데이터 앱에서 참고할 만한 레이아웃 패턴
- 데이터 앱의 신뢰성은 결국 **데이터 정제·검증**과 **중앙 집중화된 시맨틱 지표 정의**에 달려 있다는 점을 강조
- 10월 시리즈 주제였던 **데이터 흐름에 에이전트 통합하기**의 마무리 콘텐츠

> 짧은 데모·회고 성격의 영상이라 구체적인 API, 코드, 설정 방법은 나오지 않습니다.
