## 🔑 핵심 요약
- 대부분의 AI 에이전트가 프로덕션에서 실패하는 이유: **단일 프롬프트로는 실행 순서·안전성 검사·사람의 승인(Human-in-the-loop)을 보장할 수 없음**
- Google **Agent Development Kit (`ADK`)** 로 완전 자율형 **멀티모달 AI 비디오 스튜디오**를 처음부터 구축하는 데모
- `Gemini`(입력 이해) + `Imagen`(포스터 이미지 생성) + `Veo`(영상 렌더링)를 하나의 에이전트 파이프라인으로 조합

---

## 📣 주요 발표 내용
- 예시 시나리오: 매일 "cozy-spooky" 콘셉트 영상을 올리는 가상 채널 **"VibeTube"** 운영
- 시청자가 밤마다 보내는 **멀티모달 입력**(음성 메모, 현관 영상, 으스스한 사진, 텍스트 댓글)을 에이전트가 수집·처리
- `Gemini` 가 다양한 형식의 아이디어를 읽고 해석
- `Imagen` 이 썸네일/포스터 이미지를 생성
- `Veo` 가 최종 영상을 렌더링

---

## 💡 개발자 포인트
- 프로덕션 에이전트는 "큰 프롬프트 하나"가 아니라 **단계가 명시된 워크플로**로 설계해야 순서 보장이 가능
- **안전성 검사(safety check)** 를 파이프라인의 독립 단계로 분리하는 구조가 핵심
- 게시 등 되돌리기 어려운 작업 전에는 **사람의 승인 단계**를 넣는 패턴 권장
- `ADK` 를 사용하면 Gemini·Imagen·Veo 같은 여러 생성 모델을 하나의 에이전트 오케스트레이션으로 묶을 수 있음

> 영상 설명이 중간에 잘려 있어 구체적인 `ADK` API·에이전트 구성(Sequential/Parallel 등)·코드 예시는 확인되지 않았습니다.
