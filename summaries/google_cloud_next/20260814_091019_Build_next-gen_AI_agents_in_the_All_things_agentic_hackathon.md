# Build next-gen AI agents in the All things agentic hackathon

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=5Xw3LtPeByE
- **요약 일시**: 2026-08-14 09:10:19

---

## 🔑 핵심 요약
- Google Cloud가 차세대 자율 AI 에이전트 구축을 위한 글로벌 해커톤 **All Things Agentic** 론칭
- 총 **$180,000** 상금(현금 + Google Cloud 크레딧), 제출 기간: 2026년 8월 3일 ~ 8월 31일
- 필수 조건: **Gemini 3** 이상 모델 + 지원 개발자 도구 + Google Cloud 서비스 사용

---

## 📣 주요 발표 내용
- 3가지 참가 트랙:
  - **Track 1 - The Taskmaster**: 이벤트 감지, 도구 조율, 사람 감독 없이 멀티스텝 워크플로우 자동 완수
  - **Track 2 - The Collaborative Partner**: 대화 맥락을 기억하며 사용자와 함께 성장하는 인텔리전트 협업 에이전트
  - **Track 3 - The Fortified Enterprise Fleet**: 부서 간 협업·장기 실행·보안 컴플라이언스를 갖춘 엔터프라이즈 에이전트 네트워크
- 스타트업은 별도 **Startup Excellence Prize** 추가 경쟁 가능
- 보너스 점수 획득 방법:
  - `Gemma` 또는 `veo` 등 추가 Google AI 모델 사용
  - 빌드 과정을 블로그·팟캐스트·영상으로 공개
  - SNS에 `#allthingstechhackathon` 태그로 프로젝트 게시

---

## 💡 개발자 포인트
- **필수 개발자 도구** 중 하나 이상 사용해야 함:
  - `Agent Development Kit` / `Gen AI SDK` / `Genkit`
- **필수 Google Cloud 서비스** 중 하나 이상 사용:
  - `Cloud Run`, `Firestore`, `Cloud SQL`, `Cloud Storage`, `Enterprise Agent Platform`
- 제출 시 필수 포함 항목:
  - 공개 코드 저장소 + `README` (설치·실행 가이드)
  - 에이전트 아키텍처 다이어그램 (Gemini & Google Cloud 활용 방식 명시)
  - 최대 **4분** 데모 영상 (실시간 동작 + Google Cloud 배포 증명 포함)

> 단순한 루프(tied loop) 에이전트는 평가 대상이 아님. **비동기 백그라운드 동작, 복잡한 워크플로우 관리, 사용자 대리 실행** 능력이 핵심 기준.
