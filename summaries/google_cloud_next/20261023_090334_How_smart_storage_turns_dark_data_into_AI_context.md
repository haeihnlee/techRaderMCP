# How smart storage turns dark data into AI context

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=w0p3D6dk7u8
- **요약 일시**: 2026-10-23 09:03:34

---

## 🔑 핵심 요약
- 기업 데이터 대부분은 서버 곳곳에 흩어진 비정형 **다크 데이터**(PDF, 스캔 파일, 미디어 파일) 상태로 방치되어 있음
- **스마트 스토리지**는 데이터가 저장된 위치에서 바로 비정형 데이터를 식별·분류하여 별도 **ETL 파이프라인** 없이 AI가 활용할 수 있게 함
- 분류된 데이터는 **지식 카탈로그(Knowledge Catalog)**에 매핑되고, 에이전트가 이를 바탕으로 추론함

---

## 📣 주요 발표 내용
- **스마트 스토리지**: 저장 위치(in-place)에서 비정형 데이터를 자동 식별·분류
- **지식 카탈로그**와 스마트 스토리지를 결합해 흩어진 데이터를 하나의 AI 컨텍스트로 통합
- 기존 방식: 팀이 직접 추출·변환·적재(**ETL**) 파이프라인을 구축하고 일일이 색인화해야 했음
- 새 방식: 데이터를 옮기지 않고 저장소 단에서 분류 → 카탈로그 매핑 → 에이전트가 추론에 활용

---

## 💡 개발자 포인트
- RAG/에이전트용 데이터 준비 단계에서 **커스텀 ETL·인덱싱 파이프라인 구축 부담 감소** 기대
- PDF·스캔본·미디어 등 **비정형 데이터 자산을 데이터 이동 없이** AI 컨텍스트로 노출하는 아키텍처를 검토할 만함
- 에이전트가 참조할 메타데이터 계층으로 **지식 카탈로그** 설계·거버넌스가 중요해짐
