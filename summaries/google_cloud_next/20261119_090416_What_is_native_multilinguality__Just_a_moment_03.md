## 🔑 핵심 요약
- **Gemini**는 **100개 이상의 언어**를 이해하고 응답할 수 있는 **네이티브 다국어(native multilinguality)** 모델
- 입력(지침·데이터)과 출력 모두 어떤 언어든 가능하며, **여러 언어를 섞어서** 사용 가능
- 데모: 1789년 프랑스 인권 선언문(Markdown, 17개 조항)을 4개 언어로 동시 번역, 가장 긴 번역도 **약 15초** 내 완료

---

## 📣 주요 발표 내용
- Gemini의 지원 언어는 100개 이상이며 공식 목록으로 확인 가능
- 프롬프트 지침과 입력 데이터의 언어가 서로 달라도 처리 가능
- 출력도 단일 언어 또는 여러 언어 조합으로 생성 가능
- 데모에서는 **단 하나의 번역 프롬프트 템플릿**으로 영어·중국어·힌디어·스페인어 번역 요청 4건을 병렬 실행
- 입력이 **Markdown** 형식이면 번역 결과도 Markdown으로 나와 **레이아웃이 그대로 유지**됨

---

## 💡 개발자 포인트
- 언어별로 따로 프롬프트를 만들 필요 없이 **대상 언어만 파라미터로 바꾸는 템플릿 하나**로 다국어 번역 파이프라인 구성 가능
- 여러 언어 번역 요청을 **병렬(동시) 호출**하면 전체 처리 시간을 크게 줄일 수 있음
- 문서 구조(헤딩, 목록 등)를 보존하려면 원문을 **Markdown**으로 넘기는 것이 유리
- 다국어 사용자 입력(코드 스위칭 포함)을 별도 언어 감지·전처리 없이 바로 모델에 넣을 수 있음

> 영상은 짧은 소개용 데모로, 번역 품질 평가 수치나 언어별 성능 차이는 다루지 않음 — 운영 적용 전 대상 언어별 품질 검증 필요
