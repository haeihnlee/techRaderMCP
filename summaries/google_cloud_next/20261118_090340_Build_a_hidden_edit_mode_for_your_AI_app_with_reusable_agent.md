# Build a hidden edit mode for your AI app with reusable agent skills

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=1fJVOyLmtOI
- **요약 일시**: 2026-11-18 09:03:40

---

## 🔑 핵심 요약
- **Anti-Gravity + Gemini**로 개발 모드에서만 보이는 **컴포넌트 개발자 인스펙터(Dev Inspector) 페이지**를 만들어, 특정 UI 상태까지 클릭해 들어가지 않고도 바로 재현·수정하는 방법을 소개
- 인스펙터 생성 과정을 재사용 가능한 **에이전트 스킬**(`컴포넌트 인스펙터 생성기`, 컴포넌트 업데이트 스킬)로 만들고, 세션 단위 **규칙(Inspector Edit Mode)** 으로 자동화
- 핵심 철학: **작게 시작 → 프로세스 다듬기 → 하나를 완성 → 확장 → 스킬화 → 규칙화 → 자동화 → 에이전트화**

---

## 📣 주요 발표 내용
- 데모 앱: Gemini 기반 **AI 개인 트레이너 앱**(주간 운동 계획, 코치 채팅, 일일 운동 제안 카드 등)
- 개발 모드 전용 버튼 → **개발자 허브 페이지** → 뷰별로 정리된 컴포넌트 탐색기 제공
- 컴포넌트별 인스펙터 페이지 구성
  - **빠른 프리셋**: 환영 상태, 일일/주간 제안, AI 생각 중 상태 등
  - 상태를 3가지로 분류: **편집 가능한 상태**, **props로부터의 상태**(편집 가능), **계산된 상태**(읽기 전용)
  - 하단에 평이한 영어로 쓰인 **테스트 목록** — 테스트를 클릭하면 해당 상태로 컴포넌트가 설정되고, 반대로 UI를 조작하면 활성화된 테스트가 표시됨(양방향 연동)
  - `마지막 업데이트` 칩으로 인스펙터 페이지 생성 시점 표시
- 인스펙터 안의 컴포넌트는 앱과 **동일한 실제 컴포넌트**라서 코드 변경이 즉시 반영됨
- 프롬프트 한 줄("일일 운동 제안 카드용 개발자 인스펙터 뷰 만들어줘")로 Gemini가 약 **7분** 만에 새 인스펙터 생성
- **Inspector Edit Mode 규칙**: "인스펙터 모드로 바꿔줘/해제해줘"로 토글하고, 모드가 켜져 있으면 컴포넌트 수정 시 인스펙터 페이지도 같은 요청 안에서 함께 업데이트
- 스킬 프롬프트·규칙 파일은 영상 설명란에 공개 → 프로젝트에 추가만 하면 바로 사용 가능
- 마지막 데모: 인스펙터 모드에서 **코치 채팅 오류 상태**(API 키 실패 등) + 재시도 기능 추가를 요청

## 💡 개발자 포인트
- 깊은 UI 상태를 재현하려고 **매번 Gemini API를 다시 호출할 필요가 없어** 토큰·API 호출·시간이 절약됨
- 인스펙터의 상태/props 정보는 **코드를 분석해 생성된 스냅샷**이라 코드가 바뀌어도 자동 동기화되지 않음
> ⚠️ 인스펙터 페이지는 특정 시점에 고정됨 — 런타임 introspection 대신 **업데이트 스킬** 또는 **Inspector Edit Mode**로 갱신해야 함
- 모든 컴포넌트에 자동 적용하지 말고 **필요한 컴포넌트에만** 생성(채팅 말풍선 같은 단순 컴포넌트는 제외)
- 개발 전용 기능이 **프로덕션 빌드에 포함되지 않도록** 앱 구조를 설계해야 함(구현 전에 Gemini에게 방법부터 설명 요청)
> ⚠️ 처음 Gemini가 제안한 모드는 **전역 토글**이라 새 세션에도 유지됨 → **세션 단위 스코프**로 수정해야 했음
- 작업 팁
  - 바로 구현시키지 말고 "변경하지 말고 옵션부터 논의하자"로 **선택지를 먼저 받기**
  - 질문하는 과정 자체가 **대화 컨텍스트를 쌓는** 효과가 있음
  - 컴포넌트 한정 변경은 그대로 진행하고, 방식 자체가 바뀌면 **페이지와 스킬을 함께 업데이트**하도록 지시
  - 결과가 안 좋으면 반복 수정보다 **버리고 새로 시작**(3번째 시도에서 성공: AI Studio PoC → Gemini 웹앱 설계(실패) → Anti-Gravity에서 단일 컴포넌트부터)
- 데모 중 발견된 이슈: 수락/거부 뷰가 대기 상태와 동일하고 주간 업데이트 토글이 의도대로 동작하지 않음 → 인스펙터가 **버그를 찾는 데도 유용**함
