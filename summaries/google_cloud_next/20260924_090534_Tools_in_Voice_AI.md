## 🔑 핵심 요약
- **실시간 음성 에이전트**에서 도구 응답이 2초를 넘으면 사용자 경험이 급격히 저하됨
- 느린 도구는 즉시 응답을 반환하고, 실제 작업은 **백그라운드에서 비동기** 처리해야 함
- 빠른 도구(소리 재생·일시정지·건너뛰기 등)는 즉시 동기 실행 가능

---

## 📣 주요 발표 내용
- 음성 에이전트에서 **도구(Tool) 지연**이 대화 품질에 미치는 영향 분석
- 텍스트 환경에서 2초 지연은 무시되지만, 실시간 음성 대화에서는 **전화가 끊긴 것처럼** 느껴짐
- 도구 실행 전략 두 가지 제시:
  - **즉시 실행 가능한 도구**: 소리 재생(`play`), 일시정지(`pause`), 건너뛰기(`skip`) 등 → 동기 실행
  - **느린 도구**: 즉시 응답 반환 후 백그라운드에서 비동기 실행

---

## 💡 개발자 포인트
- 실시간 에이전트 내 모든 도구는 응답 지연 없이 즉각적으로 반응해야 함

> ⚠️ 느린 작업을 음성 응답 대기 상태로 두면 안 됨. 반드시 즉시 응답 후 백그라운드 처리.

- "살아있는 에이전트" vs "자꾸 침묵하는 에이전트"의 차이는 **도구 응답 시간 설계**에서 결정됨
- Voice AI 구현 시 도구를 **fast path** / **slow path**로 분류하고 각각 다른 실행 전략 적용 필요
