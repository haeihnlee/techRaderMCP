## 🔑 핵심 요약
- 에이전트 개발 방식이 **직접 구축**에서 **자연어 기반 자동 구축**으로 바뀌고 있음
- 지금까지는 런타임 설정, 모델 환경 설정, **워크플로우 빌더** 같은 도구로 에이전트의 단계별 지침을 직접 정의해야 했음
- 앞으로는 **Gemini**가 사람의 말만 듣고 필요한 에이전트를 자동으로 구축하고, 기술(skills)을 활용해 업무를 완수함

> 원본 자막이 짧은 티저 분량이라 구체적인 제품명·API·출시 일정은 영상에 나오지 않음

---

## 📣 주요 발표 내용
- 기존 방식: 런타임 설정, 다양한 모델 설정 도구, 워크플로우 빌더로 에이전트 동작을 단계별로 직접 명시
- 새로운 방향: 에이전트가 어떻게 동작할지 일일이 명시하지 않아도 됨
- **Gemini**가 자연어 요청을 해석해 맞는 에이전트를 자동으로 구성
- 에이전트는 **기술(skills)**을 활용해 실제 업무를 수행

---

## 💡 개발자 포인트
- 에이전트 개발의 중심이 절차를 명시적으로 설계하는 일에서 **의도(목표)를 자연어로 정확히 전달하는 일**로 옮겨가고 있음
- 기존 워크플로우 빌더 기반 파이프라인은 자연어 기반 자동 구축으로 대체될 수 있으니 적용 범위를 다시 검토해 볼 만함
- 에이전트가 활용할 **기술(skills)/도구**를 잘 정의하고 노출하는 일이 더 중요해질 것으로 보임
