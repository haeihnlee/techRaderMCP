# How to build AI agent evals in 4 steps

- **출처**: https://www.youtube.com/watch?v=FRETejqa7D8
- **요약 일시**: 2026-10-02 09:05:32

## 🔑 핵심 요약
- **LangGraph** 에이전트에 대한 평가(Evals)를 **4단계**로 간단하게 구축하는 방법 소개 (AI Agent Clinic 에피소드)
- **Antigravity**에 에이전트 소스 코드를 연결해 내부 동작을 이해시키고, 평가 지표 선별까지 맡김
- 평가 툴킷 활용으로 평가 환경 설정 기간을 **몇 주 → 약 1시간**으로 단축

---

## 📣 주요 발표 내용
- **1단계 – 소스 코드 연결**: 에이전트 소스 코드를 **Antigravity**에 연결해 에이전트의 내부 작동 방식을 파악하게 함
- **2단계 – 평가 툴킷 사용**: 평가 툴킷으로 설정 작업을 몇 주에서 한 시간 수준으로 단축
- **3단계 – 품질 기준 학습**: Antigravity에게 "양질의 결과물"이 무엇인지 알려주어 에이전트에 맞는 **평가 지표(metrics)**를 선별하도록 함
- **4단계 – 평가 실행**: 실제 평가를 돌려 다음 버전 개선을 위한 **정량적 방향**을 확보

---

## 💡 개발자 포인트
- 대상은 **LangGraph** 기반 에이전트 — 기존 에이전트 코드를 그대로 두고 평가 레이어를 추가하는 접근
- 평가 지표를 사람이 처음부터 설계하기보다, 코드 컨텍스트 + "좋은 결과 예시"를 AI 코딩 에이전트(**Antigravity**)에 제공해 지표를 도출하는 방식
- 평가 결과를 근거로 **시스템 프롬프트** 수정 등 반복 개선 루프를 돌리는 것이 핵심
> "Evals are everything" — 정량적 평가 없이 프롬프트/에이전트를 수정하면 개선 여부를 판단할 수 없음

> ⚠️ 추출된 자막이 짧아(인트로 위주) 툴킷의 구체적 이름·API·명령어는 원본 영상에서 확인 필요
