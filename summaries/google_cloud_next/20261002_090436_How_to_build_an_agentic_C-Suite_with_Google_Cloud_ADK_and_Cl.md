# How to build an agentic C-Suite with Google Cloud ADK and Cloud Run

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=6nofrnjOCNI
- **요약 일시**: 2026-10-02 09:04:36

---

## 🔑 핵심 요약
- **Google ADK(Agent Development Kit)**로 CSO·CMO·CFO 등 임원 역할 에이전트를 만들고, **오케스트레이터**가 업무를 나눠 맡긴 뒤 결과를 종합하는 **멀티 에이전트 의사결정 앱** 사례
- **Human-in-the-loop**: 최종 결정 전에 사람이 각 에이전트의 결과물을 수정하거나 잘못된 가정을 거부함
- **Cloud Run**(서버리스)에 배포해 실제 운영 비용은 **월 약 7~10달러**이며, 앱은 **오픈소스**로 공개됨

---

## 📣 주요 발표 내용
- **데모 시나리오**: B2B 클라우드 스타트업의 **아시아·태평양 확장 전략** 수립
  - 비즈니스 컨텍스트와 경쟁사 데이터를 **Markdown 파일**로 업로드한 뒤 "이사회 소집"
- **에이전트별 역할 분담**
  - **CSO**: 시장 빈틈(갭) 분석
  - **CMO**: 포지셔닝 계획
  - **CFO**: 재무 여력 평가
- **오케스트레이터**가 각 결과를 **임원 브리핑 자료**로 종합
  - 예시 결과: 경쟁사 A 대상 공격적 AI 기능 비교 + 경쟁사 B 대상 엔터프라이즈 지원 메시징의 이중 전략
  - 위험 요소와 다음 단계까지 포함
- **응용 예시**: 프롬프트·도구만 바꾸면 다른 도메인에 적용 가능
  - 부동산 자문(시장 경쟁·금리·세금 영향 분석)
  - 광고 소재 작성부터 API로 캠페인 집행까지 하는 엔드투엔드 마케팅 팀
- 발표자: **Anupam**(GDE, AI/ML Google Cloud Ambassador, Korex Consulting 운영)

## 💡 개발자 포인트
- **ADK**는 멀티 에이전트 생성과 에이전트 간 통신 기반을 제공하므로, 실제 작업은 대부분 **프롬프트 설계**임
- **품질 평가**: 각 에이전트를 **골든 데이터셋**과 비교해 테스트하는 방식을 권장하며, ADK 공식 문서에 평가(evaluation) 섹션이 따로 있음
- **배포**: `Cloud Run`은 요청이 있을 때만 과금되는 서버리스 구조라 사용량이 적거나 들쭉날쭉한 에이전트 워크로드에 적합함
- **활용 패턴**: "입력 데이터 → 결과물 생성"을 반복하는 업무라면 에이전트로 자동화할 수 있음

> ⚠️ 고위급 의사결정을 자동화할 때는 **Human-in-the-loop 검증 단계**를 반드시 두는 것을 권장함. 에이전트가 잘못된 가정을 세울 수 있기 때문.
