# Supercharge your coding agent with the Google Cloud Developer Plugin

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=_qVCARkqR30
- **요약 일시**: 2026-09-11 09:07:23

---

## 🔑 핵심 요약
- **Google Cloud Developer Plugin**은 MCP 서버와 에이전트 스킬을 하나로 묶은 올인원 플러그인
- `gdcloud` CLI 인증 스킬 포함, Google Cloud 문서에 직접 접근 가능
- **100개 이상의 스킬 저장소**에서 자동으로 적합한 스킬을 탐색·적용

---

## 📣 주요 발표 내용
- **Developer Knowledge MCP Server** 포함: Google 기술 문서에 직접 접근, 정확한 정보 제공
- 지원 에이전트: `Cloud Code`, `Codecs`, `Anti-Gravity`, 그 외 **Agent Plugin Standard** 지원 에이전트
- 내장 스킬:
  - `gdcloud` 커맨드라인 인증
  - Google Skills Repository 전체(100+ 스킬)에서 목적에 맞는 스킬 자동 검색

---

## 💡 개발자 포인트
- 기존 Developer Knowledge MCP Server의 상위 호환 — 플러그인 하나로 MCP + 스킬을 동시에 사용 가능
- **Agent Plugin Standard**를 지원하는 모든 에이전트에서 동일하게 작동
- 스킬 자동 탐색 기능 덕분에 어떤 작업을 하려는지 설명만 하면 적합한 스킬이 자동 연결됨

> 기존에 Developer Knowledge MCP Server만 사용 중이라면 Google Cloud Developer Plugin으로 마이그레이션하는 것을 권장. 동일한 MCP 기능에 스킬 레이어가 추가됨.
