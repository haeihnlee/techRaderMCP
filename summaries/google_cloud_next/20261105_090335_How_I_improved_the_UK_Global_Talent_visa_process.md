# How I improved the UK Global Talent visa process

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=Am6u6Avn11I
- **요약 일시**: 2026-11-05 09:03:35

---

## 🔑 핵심 요약
- **Get in those**는 영국 **Global Talent Visa** 신청자가 정부 심사 전에 서류를 미리 평가받도록 돕는 앱
- **Cloud Run** 위에 **10개의 AI 에이전트**를 구축해 각 증빙 서류를 지침 기준으로 검토
- 에이전트들이 **병렬**로 동작하므로 에이전트 1개와 비슷한 비용으로 10개를 운용

---

## 📣 주요 발표 내용
- 대상 문제: 아프리카·인도 등에서 지원하는 사람에게 변호사 사전 평가 비용(**수천 달러**)이 큰 부담
- 앱이 각 증빙 서류가 비자 지침을 완벽히 준수하는지 꼼꼼히 확인
- 각 에이전트가 의견을 내고, 이를 모아 비자 진행 **추천 / 비추천**에 대한 **합의된 의견(consensus)** 도출
- 인프라는 `Cloud Run` 기반이며, 실행되는 동안에만 과금되는 구조를 활용

---

## 💡 개발자 포인트
- **멀티 에이전트 + 합의 패턴**: 여러 에이전트가 독립적으로 판단한 뒤 결과를 집계하면 단일 모델 판단보다 신뢰도를 높일 수 있음
- **서버리스 병렬 실행**: `Cloud Run`은 요청 처리 시간 기준으로 과금되므로, 에이전트를 순차가 아닌 병렬로 돌리면 전체 실행 시간(=과금 시간)을 크게 줄일 수 있음
- 문서 검토처럼 **지침 준수 여부를 체크리스트로 판정**하는 업무는 에이전트별로 기준을 나눠 맡기기 좋음
> 영상 속 "1개 비용으로 10개" 주장은 실행 시간 기준의 설명이며, 실제로는 인스턴스 수·동시성 설정·LLM API 호출 비용에 따라 총비용이 달라질 수 있으니 별도로 따져봐야 함
