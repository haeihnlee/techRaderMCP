# How to build and deploy powerful data apps with agents

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=UZiDvf2IDl0
- **요약 일시**: 2026-10-17 09:03:31

---

## 🔑 핵심 요약
- **AI 에이전트**(Antigravity, Cloud Code 등)로 프롬프트만으로 맞춤형 **데이터 앱**을 만들고 **Looker 안에서 바로 호스팅**하는 흐름을 보여주는 데모
- 앱은 관리형 **LookML 시맨틱 계층**에 직접 연결되므로 UI는 마음대로 만들면서 **시맨틱 계층의 보안 이점**은 그대로 유지
- 로컬 미리보기 → 디자인 조정 → **게시 프롬프트 한 번**으로 몇 분 만에 배포 완료

---

## 📣 주요 발표 내용
- 설치 스크립트를 터미널에서 작업 공간(workspace)에 바로 연결해 프로젝트를 초기화
- 설정할 때 **Looker 인스턴스 URL**, **API 클라이언트 ID / 시크릿**, 대상 **폴더 ID**를 입력
- 작업 공간에서 원하는 AI 에이전트(**Antigravity**, **Cloud Code**)를 실행하고 자연어 프롬프트로 UI 생성
- 데모: 항공편 데이터를 써서 **3개 탭 구성의 맞춤형 UI** 생성
- 로컬 미리보기에서 레이아웃·색상·형식을 조정하고 사진·로고 업로드 가능
- 게시 프롬프트로 Looker에 **완전 관리형 데이터 앱**으로 배포되고, 공유받은 사용자만 볼 수 있음

---

## 💡 개발자 포인트
- 폴더 ID는 Looker에서 '내 폴더(my folder)'를 열었을 때 **URL 끝에 붙은 숫자**를 쓰면 됨
- 기존 Looker 대시보드로는 어렵던 **JavaScript 수준의 인터랙션**과 반응형 위젯을 구현할 수 있음
- 데이터 접근은 **LookML 시맨틱 계층**을 거치므로 지표 정의와 권한 모델을 앱에서 다시 구현할 필요가 없음
- 별도 호스팅 인프라 없이 Looker가 앱을 호스팅·관리함
> API 클라이언트 시크릿을 작업 공간에 입력하므로, 저장소에 커밋되거나 에이전트 컨텍스트에 노출되지 않게 관리해야 함
