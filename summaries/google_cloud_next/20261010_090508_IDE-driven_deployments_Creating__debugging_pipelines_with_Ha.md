# IDE-driven deployments: Creating & debugging pipelines with Harness and Google Cloud

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=jX-EGkYIhsI
- **요약 일시**: 2026-10-10 09:05:08

---

## 🔑 핵심 요약
- **Harness**(지능형 DevSecOps 플랫폼)가 Google **Antigravity IDE** + **Gemini**와 연동되는 확장 기능을 소개
- IDE를 떠나지 않고 자연어로 **배포 파이프라인 생성·수정**이 가능
- 실패한 배포의 **원인 분석과 해결 방법 제시**까지 IDE 안에서 처리

---

## 📣 주요 발표 내용
- **IDE에서 파이프라인 생성**: 빌드 → 승인 절차/보안 스캔 → **Kubernetes** 클러스터 배포 흐름을 자연어로 요청
- **카나리(canary) 배포** 전략을 파이프라인에 바로 구성
- 신규 생성뿐 아니라 **기존 파이프라인 업데이트**도 지원
- **템플릿 + 정책(Policy)** 을 적용해 엔터프라이즈급 거버넌스 확보
- 생성 전에 **계획(Plan)** 을 만들어 보여주고, 사용자가 검토·승인하는 단계 제공
- 아키텍처 뷰와 Harness의 기반이 되는 **`YAML` 파일**이 함께 생성됨
- 생성된 파이프라인은 **Harness UI**에서 단계별(카나리 단계 ~ 최종 배포)로 확인 가능
- **배포 트러블슈팅**: 가장 최근 실패한 배포를 조회하면 원인(예: **파라미터 누락**)과 연결된 서비스를 즉시 파악
- **경향 분석**: 최근 20건 배포를 분석해 서비스별 파이프라인, 실패 횟수, 실패 원인, 해결 방법을 목록으로 제공
- 분석 결과를 보고만 하는 데 그치지 않고 IDE에서 **바로 조치·수정** 가능

---

## 💡 개발자 포인트
- 앱 코드 작성 → PR → 배포까지의 흐름에서 **파이프라인을 미리 따로 준비할 필요가 줄어듦**
- 파이프라인 정의는 결국 **`YAML`** 로 남으므로 버전 관리와 코드 리뷰 대상에 넣을 수 있음
- AI가 만든 파이프라인은 **Plan 검토·승인 단계**를 거치니, 거버넌스 정책과 템플릿을 미리 정해 두는 게 좋음
- 개별 실패 디버깅뿐 아니라 **여러 배포에 걸친 공통 실패 패턴**을 찾을 때도 쓸 수 있음

> 시작 방법: **Antigravity** 확장 프로그램 메뉴에서 **Harness**를 검색해 설치
