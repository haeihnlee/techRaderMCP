# What exactly is an Agent Harness?

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=_6qHmJ9Trmg
- **요약 일시**: 2026-09-29 09:07:41

---

## 🔑 핵심 요약
- **AI 에이전트**는 **LLM(대형 언어 모델)** + **에이전트 하니스(Agent Harness)** 두 요소로 구성됨
- **하니스**란 AI 에이전트에서 LLM을 제외한 모든 나머지 구성 요소를 총칭하는 개념
- LLM 단독으로는 외부 정보가 필요한 질문에 답할 수 없으며, 하니스가 도구 호출·정보 수집을 대신 담당

---

## 📣 주요 발표 내용
- AI 에이전트의 두 핵심 구성 요소 명확화
  - **모델(LLM)**: 추론·생성 담당 — 예) `Gemini Flash`
  - **하니스**: 도구 실행·컨텍스트 주입·정보 검색 담당 — 예) `Google Anti-Gravity`
- 하니스가 하는 일
  - 사용자 질문을 LLM에 전달
  - LLM이 요청한 외부 정보(날씨, DB 등)를 실제로 수집
  - 수집한 정보를 원래 질문과 함께 LLM에 재전달하여 최종 답변 생성

---

## 💡 개발자 포인트
- 일반 챗봇 대화처럼 보여도 실제로는 **거의 항상 에이전트와 상호작용**하는 구조
- LLM이 "더 많은 정보가 필요하다"고 판단하면 **하니스가 도구(tool)를 호출**하고 결과를 다시 LLM에 주입하는 **루프 구조**
- 예시 흐름:
  1. 사용자: "우비 입어야 해?"
  2. LLM → 날씨 정보 없음 → 하니스에 날씨 조회 요청
  3. 하니스 → 날씨 API 호출 → "맑음, 37도" 반환
  4. LLM → "우비 불필요" 최종 답변

> **주의**: LLM 자체만 교체하거나 하니스 로직만 바꾸는 등 두 레이어를 **독립적으로 교체/업그레이드** 가능하다는 점이 아키텍처 설계의 핵심
