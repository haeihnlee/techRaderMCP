# Do more with fewer tokens: Gemini Smart Routing

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=BQgm_qLll3A
- **요약 일시**: 2026-10-24 09:03:45

---

## 🔑 핵심 요약
- **Gemini 스마트 라우팅(Smart Routing)** 발표 소개: 에이전트 작업을 **토큰 효율적**으로 처리하는 기능
- **실시간 지출 한도**를 세부 수준으로 설정하면 시스템이 하위 작업을 **가장 빠르고 효율적인 모델**로 자동 라우팅
- 앞으로 모든 조직은 **토큰 사용량과 에이전트 성과 사이의 균형**을 맞춰야 한다는 메시지

---

## 📣 주요 발표 내용
- 에이전트 도입 팀들이 자주 겪는 **토큰 제한** 문제를 해결하려는 기능으로 소개됨
- 세부 단위(granular)로 **실시간 지출 한도(spend limit)** 설정 지원
- 작업을 하위 작업(sub-task)으로 나눠, 각각을 처리할 수 있는 **최적 모델로 자동 라우팅**

> 참고: 원본은 짧은 소개 영상이라 구체적인 API명, 설정 방법, 지원 모델 목록, 가격 정보는 나오지 않습니다.

---

## 💡 개발자 포인트
- 에이전트 워크로드에서 **모델 선택을 직접 하드코딩하지 않고** 라우팅 계층에 맡기는 구조를 검토해 볼 만함
- 비용 관리를 **사후 모니터링**이 아니라 **실시간 한도 설정**으로 다루는 방향
- 에이전트 설계 시 **토큰 예산 대비 작업 성공률**을 핵심 지표로 함께 관리할 필요가 있음

> 주의: 실제 적용 전에 공식 문서에서 라우팅 기준, 품질 보장 범위, 한도 초과 시 동작을 확인해야 합니다.
