# GPUs made easy

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=uKkKOHpesgs
- **요약 일시**: 2026-11-05 09:04:17

---

## 🔑 핵심 요약
- **Cloud Run 서버리스 GPU**를 쓰면 VM이나 Kubernetes 클러스터를 직접 프로비저닝하지 않고도 AI 모델을 서빙할 수 있음
- 언어와 관계없이 **Docker 컨테이너로 만들 수 있으면** Cloud Run에 배포 가능
- 해커톤 프로토타입 **Dr. Cloud**에서 시작해, 현재는 이식 외과의와 함께 신장 이식 의사결정 지원 앱을 개발 중

---

## 📣 주요 발표 내용
- 서버리스 GPU의 장점으로 **확장성**, **유연성**, **비용 최적화**, **단일 엔드포인트**로 여러 고객에게 서빙하는 점을 소개
- 기존 GCP GPU 방식은 전용 VM이나 GKE 클러스터를 직접 구성하고 **NVIDIA CUDA 드라이버**를 관리해야 했음
- Cloud Run은 이 인프라 관리를 **추상화**함
- 사용자가 늘면 Cloud Run이 **인스턴스와 GPU를 함께 자동으로 스케일업**함
- 사례: 독감을 앓던 중 WebMD를 뒤지는 대신 더 나은 방법이 필요하다고 느껴 의료 상담 앱 Dr. Cloud를 만듦
- 이 프로토타입을 계기로 외과의 2명과 협업해 **신장 이식 수락·거절 결정**을 돕는 앱으로 발전함

---

## 💡 개발자 포인트
- Python, React, JavaScript 등 스택에 상관없이 **컨테이너화가 배포 조건의 전부**임
- 권장 워크플로우는 미리 만들어진 Docker 이미지를 출발점으로 쓰는 것:
  - **Deep Learning VM** 기반 이미지
  - 미리 구성된 **Gemma** / **Llama** LLM 컨테이너
- 기본 이미지를 고른 뒤 **애플리케이션 코드**를 교체하고 `requirements.txt` 경로를 바꾸면 배포 준비가 끝남
- 기존 ML 모델과 로컬 LLM 모두 같은 방식으로 Cloud Run GPU에 올릴 수 있음
- 연사는 실제 작업이 예상보다 훨씬 쉬웠다고 말함

> 주의: 영상이 짧은 소개 영상이라 GPU 종류, 리전, 가격, 콜드 스타트 같은 구체적인 스펙은 나오지 않음. 실제로 도입하려면 Cloud Run GPU 공식 문서를 따로 확인해야 함
