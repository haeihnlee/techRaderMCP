# Grounding agents in your trusted semantic models using Knowledge Catalog

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=IW5XI2_1ctI
- **요약 일시**: 2026-11-07 09:03:58

---

## 🔑 핵심 요약
- **Knowledge Catalog Studio**가 여러 플랫폼의 **시맨틱 레이어**를 자동으로 인덱싱해, AI 에이전트가 검증된 비즈니스 맥락을 바탕으로 답변하게 함
- Knowledge Catalog에 연결된 **그라운디드 에이전트**는 도구 3개만으로 정확한 답을 냄 (비교 대상 에이전트는 핵심 필터를 놓쳐 치명적 오류 발생)
- 데모 기준 **지연 시간과 토큰 사용량이 둘 다 약 67% 감소** — "시맨틱은 한 번 정의하고 에이전트 그라운딩은 어디서든"

---

## 📣 주요 발표 내용
- 자동 인덱싱 대상 시맨틱 소스: **Looker ML**, **BigQuery 그래프**, **dbt MetricFlow**, **Databricks Unity Catalog**, **Snowflake**, **SAP**
- "Knowledge Catalog에 어떤 데이터가 있지?" 같은 자연어 질문 지원, 검색 범위는 조직 전체 또는 특정 GCP 프로젝트
- 답변마다 **시각적 맥락 그래프**를 동적으로 생성
- 그래프 구성: 노드 = 데이터 자산·시맨틱 모델, 컨테이너 = 같은 상위 리소스를 공유하는 항목 묶음, 에지 = 항목 간 연결
- 노드 상세 패널: 스키마, 메트릭 로직, 정의, 조인, 파일 경로, 연결된 노드
- 노드를 펼치면 **업스트림·다운스트림 리니지** 확인 가능
- dbt 연동: 팩트 테이블 시맨틱, SQL 정의가 담긴 dbt test, 대시보드·성숙도 수준이 담긴 dbt exposure, macro, snapshot, 관련 BigQuery 테이블
- Snowflake 연동: 차원·측정값 정의, 모델 속성, 테이블 조인 방식, 기본 키
- SAP 연동: 외래 키 기반 조인 정의, **PII 표시 열**(예: 고객 번호), SAP 전용 메타데이터

## 💡 개발자 포인트
- 그라운디드 에이전트가 쓰는 도구는 3개: **KC 항목 검색**, **KC 맥락 조회**, **실행 탐색**
- 비교용 에이전트(지식 기반 없음)는 SQL 실행 전 테이블 정보 조회, 스키마·샘플 행 확인 등 도구를 여러 번 호출해야 함
> ⚠️ 시맨틱 맥락이 없는 에이전트가 낸 오류: VIP 정의의 **실버 등급·평생 지출 임계값** 무시, **내부 테스트 행** 미제외, **배송 주문** 누락 → 숫자가 틀림
- 비즈니스 규칙(VIP 정의, 제외 조건 등)을 시맨틱 레이어에 명시해 두면 에이전트 정확도와 거버넌스가 함께 좋아짐
- 그라운디드 에이전트는 **4턴**만에 실행을 끝냄 → 도구 호출 수, 지연 시간, 토큰 비용 절감
- 이미 쓰고 있는 dbt·Looker·Snowflake 등의 시맨틱을 그대로 재사용하므로, 에이전트용으로 다시 정의할 필요가 줄어듦
