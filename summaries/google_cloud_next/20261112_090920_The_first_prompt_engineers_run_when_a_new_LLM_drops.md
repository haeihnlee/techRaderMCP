# The first prompt engineers run when a new LLM drops

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=I7fla92ZHIk
- **요약 일시**: 2026-11-12 09:09:20

---

## 🔑 핵심 요약
- 새 **최첨단 LLM**이 공개됐을 때 엔지니어들이 플레이그라운드에 **가장 먼저 던지는 테스트 프롬프트**를 묻는 짧은 퀴즈쇼 형식 영상
- 정식 기술 발표가 아니라 가벼운 **유머/커뮤니티 콘텐츠**
- 진짜 혁신인지 과대광고인지 가리려면 이미 유명한 벤치마크보다 **도구 자체의 기능**을 직접 확인해야 한다는 의견이 나옴

---

## 📣 주요 발표 내용
- 신기능·제품 발표 없음 (짧은 클립)
- 참가자 답변 예시:
  - "**당신의 제한된 환경을 설명해 보세요**" — 모델이 자기 실행 환경·제약을 얼마나 알고 있는지 확인
  - "**자전거 타는 펠리컨**"은 이미 너무 널리 쓰여 뻔한 테스트라는 지적
  - "장모님이 몇 주 동안 머무르러 오십니다. 내 여권 어디 있지?" — 맥락 속 숨은 의도를 읽는지 보는 농담형 프롬프트
- 진행자는 정답보다 재치 있는 답변에 점수를 줌

---

## 💡 개발자 포인트
- 널리 알려진 테스트 프롬프트는 **학습 데이터에 섞였을 가능성**이 있어 새 모델의 실력을 제대로 보여주기 어려움
- 새 모델 평가는 **내 사용 사례에 맞는 기능 테스트**(도구 사용, 환경 인식 등) 위주로 직접 구성하는 게 좋음
- **암묵적 의도·유머 이해** 같은 맥락 추론 프롬프트도 간단한 정성 평가로 쓸 수 있음

> 영상 자막이 매우 짧아 구체적인 모델명·API·수치는 나오지 않음
