# Run, hunt, hack: Join the Cloud Run hackathon on product hunt

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=BxnIZfcDLN8
- **요약 일시**: 2026-10-10 09:07:02

---

## 🔑 핵심 요약
- **Google Cloud Run 해커톤**이 **Product Hunt**에서 **10월 14일(수)** 열림
- 로컬에만 있던 사이드 프로젝트(앱·웹사이트·게임)를 **Cloud Run**에 배포하고 Product Hunt에 출시하는 방식
- 상품으로 **$500 상당 Google Cloud 크레딧** 등 제공, 신규 가입자는 선착순 **$50 크레딧** 지급

---

## 📣 주요 발표 내용
- **Cloud Run 해커톤 개최**: Product Hunt 플랫폼과 연계한 출시형 해커톤
- **간단한 배포**: 명령어 하나로 프로젝트를 **Cloud Run**에 배포 가능 (예: `gcloud run deploy`)
- **완전 관리형 인프라**: Cloud Run이 인프라 관리를 맡고, 트래픽에 따라 **자동 확장(autoscaling)**
- **커뮤니티 지원**: Product Hunt 포럼에서 **Google 직원** 및 **Google Developer Experts(GDE)**와 직접 소통 가능

---

## 💡 개발자 포인트
- Cloud Run을 처음 쓰더라도 컨테이너/소스 기반 배포로 진입장벽이 낮음
- 사이드 프로젝트를 공개 URL로 빠르게 서비스하고 Product Hunt 출시까지 한 번에 경험할 수 있는 기회
- 무료 크레딧으로 비용 부담 없이 서버리스 배포를 실습 가능

> ⚠️ 가입 시 제공되는 **$50 크레딧은 선착순** 제공이므로 조기 가입 필요
