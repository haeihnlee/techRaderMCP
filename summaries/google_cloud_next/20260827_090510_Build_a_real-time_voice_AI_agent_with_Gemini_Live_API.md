# Build a real-time voice AI agent with Gemini Live API

- **컨퍼런스**: Google Cloud Next
- **출처**: https://www.youtube.com/watch?v=pFc-HcUgFgY
- **요약 일시**: 2026-08-27 09:05:10

---

## 🔑 핵심 요약
- **Gemini Live API**는 기존 TTS와 달리 오디오-to-오디오 양방향 실시간 스트리밍을 지원한다
- 브라우저 → 백엔드 → Gemini Live 3-레이어 아키텍처에 WebSocket을 사용하는 핵심 루프(open→send→receive→play)로 구성
- **VAD**(음성 활동 감지), **Barge-in**(끼어들기), **Tools**(도구 호출) 세 가지가 에이전트를 "살아있는 대화"처럼 만든다

---

## 📣 주요 발표 내용
- **Gemini Live API**는 음성을 텍스트로 변환하지 않고 오디오 → 오디오 직접 처리
- 응답 완성 전에 스트리밍 시작 → 낮은 지연 체감
- 톤·쉼·에너지 등 음성 뉘앙스를 이해
- **VAD(Voice Activity Detection)** 내장 — 별도 구현 불필요
- **Barge-in** 지원: 모델이 말하는 중 사용자가 끊으면 즉시 중단 후 `interrupted` 신호 전송
- **Tools** 연동: 함수명·설명·인자를 정의하면 모델이 판단해 호출, 실제 실행은 앱 코드가 담당
- 다음 에피소드에서는 동일 앱을 **Google ADK**로 재구현 예정

---

## 💡 개발자 포인트
- WebSocket 유지 연결 필수 — 일반 HTTP 요청으로는 지속 오디오 스트림 불가
- 백엔드에서 두 작업이 **독립적으로** 동시 실행: ① 마이크 오디오 전송, ② 모델 오디오 수신
- Barge-in 구현 시 네트워크 신호 대기 없이 **로컬에서 즉시 오디오 재생 중단**해야 자연스럽게 느껴짐
- 무음 구간에도 오디오 스트림을 **꾸준히 전송**해야 VAD가 발화 시작 시점을 정확히 감지

> **주의:** Tool 실행 시간이 길어지면 대화가 무음 상태가 됨. Tool은 명령만 확인하고 즉시 반환 후 비동기 처리할 것.

- 데모에서는 **JAI SDK** 직접 사용으로 모든 구성요소를 노출; ADK는 세션·스트리밍 루프·큐를 프레임워크가 관리
